# 钢四人物小传MOD · 黄金存档制度（钢四裁剪版）

> 状态：2026-08-20 门二已拍板（全量落地）并落地本仓库。
> 定位：移植《开局一键爽玩》`docs/testing/黄金存档制度.md`，按本 MOD 裁剪——本 MOD 无自检机制，黄金存档即每轮实测的固定复现起点（1936/1939 各一份），保证每轮实测起点一致、可追溯。

## 一、登记规则

1. 每个黄金存档必须登记六项：用途、游戏版本（`logs\code_revisions.log` 的 `game_hash_short`）、MOD 版本线、创建日期、SHA-256、本机位置（`C:\Users\Admin\Documents\Paradox Interactive\Hearts of Iron IV\save games\`）。
2. 哈希入仓：登记表在本文件下方；二进制 `.hoi4` 不入 git（50 MB 级），只留本机 `save games\`。
3. 黄金存档一旦被实测轮次修改，需另存新档（如 `cbio_gold36` → `cbio_gold36a`），不得覆盖原档；原档哈希保持不变。
4. 建议档名：`cbio_gold36.hoi4`、`cbio_gold39.hoi4`（与爽玩 `test*` 系列区分）。

## 二、使用规则

1. 每轮实机回归从黄金存档加载，按当轮 `清单.md` 点验；实测后另存判定档（如 `cbio_gold36_v130e-test1.hoi4`），判定档不入登记表。
2. 判定档不升格为黄金存档；仅当功能基线发生版本化变化时，由机主拍板重建黄金存档并更新登记。
3. 游戏版本升级导致旧黄金存档不可载时，视为版本升级复合风险：重建基线存档并复跑当轮基线实测。
