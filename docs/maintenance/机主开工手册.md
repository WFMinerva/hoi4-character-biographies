# 钢四人物小传MOD · 机主开工手册

> 定位：给机主本人的最短页——怎么交互、哪些事只有您能做。AI 侧流程见《维护与重构标准流程_适配版》，安全红线见根 `AGENTS.md`。

## 1. 开工与交互

- 新会话直接用自然语言说明当前任务即可（DSH 会自动加载根 `AGENTS.md`；其他工具按 `AGENTS.md` 权威文档指针节取读）。
- 机器环境（Python、游戏路径、steamcmd、模型配置）以本机运行时实际为准，不写入共享文档。
- 自然语言即可推进工作：「拍板」「开始」「试玩没问题」等只是表达示例，任何清楚的日常表达同样有效，AI 不得要求您说固定口令。
- 唯一例外：**推送**涉及外部写入，必须您明确说出「推送」；AI 不得从「确认」「照批」「按推荐」推断提交或推送授权。
- AI 报告到确认点时会给 2–4 个建议选项（推荐项标注在前，各附一句取舍）；您点选、回「选 n」/「按推荐」或自由回复均可。

## 2. 证据分级提醒

AI 报告里的状态分级，只有您实机确认过的才是「实机确认/用户确认」；其余只是「文件确认/静态确认/日志确认」，别被文字混淆。

## 3. 只有您能做的三件事

1. **实机测试**：AI 部署测试包后，您进游戏开 1936/1939 剧本点验，结束后**不用转发日志**——AI 直接从游戏用户目录 `logs\`（本机路径运行时确认）读取判读（error.log / text.log / game.log / setup.log）。
2. **黄金存档**：回归从黄金存档出发（1936/1939 各一份，登记与使用规则见 `docs/testing/黄金存档制度_钢四裁剪版.md`）；实测后另存判定档，不覆盖黄金档。
3. **工坊上传**：AI 准备到登录前（构建包、逐文件哈希核对、VDF、changenote），然后您本人执行 steamcmd（流程见 `docs/WORKSHOP_UPLOAD.md`）。密码与 Steam Guard 验证码只您输入，不写入任何文件、不告诉 AI。

## 4. 纪律速查

- 完整版和兼容版**不能同时启用**（二选一）。
- 报障格式：人物名＋国家＋剧本＋（最好有）截图，其余排查由 AI 做。
- AI 说「稳定版」前，必须您实机确认过；您没确认前只能是「测试包 / 阶段性可接受」。
