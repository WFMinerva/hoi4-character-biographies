# 审计底库使用说明

> 总入口：根目录`AGENTS.md`；当前版本状态以`docs/CURRENT_BASELINE.md`为准。

`audit/data/`保存v130a—v130b阶段的机器扫描与人工语义复核成果。它们是历史基线快照，不自动代表当前v130c7源码的最新统计。

## 文件用途

- `v130a-1d_总览与优先问题.*`：国家、来源、优先级和例外总览。
- `v130a-2_静态身份*`：6421条静态身份实例的结构底账。
- `v130a-3_动态显示路径*`：7906条有效动态人物路径及机器候选。
- `v130a-4b_本地化与文件哈希*`：本地化键、BOM、重复键、包结构和文件哈希审计。
- `v130b_只读复核*`：六个角色文件同步、52个临时键清理及七个国家历史文件保留证据。

## 使用限制

- 机器候选不是确认BUG。
- 人名/键名相似匹配不得使用通用模糊匹配：difflib曾把陈云误配为陈毅、张伟误配为张闻天。只接受同后缀精确匹配或有证据的前缀/改名关系，宁可漏判也不错配。
- 旧行号在游戏或MOD文件更新后可能失效。
- 旧“当前基准”版本号不得覆盖`docs/CURRENT_BASELINE.md`。
- 人工裁定优先于机器分类。
- 对新游戏版本重新扫描时，应保留旧数据，不原地覆盖；用新版本号建立新目录。
