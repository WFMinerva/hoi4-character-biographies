结论：六个角色文件同步后，这52个键全部成为孤儿键，可直接删除整个本地化文件，无需逐行编辑。

## 三、旧筛查口径的问题

旧筛查使用“desc行数净增为0”以及“剔除desc后与原版相同”作为可删除候选条件。

该规则会误判下列有效覆盖：

```text
desc = ""  →  desc = CBIO_*_desc
原版desc键 →  CBIO_*_desc
```

虽然 `desc` 行数没有增加、文件的非desc部分也完全相同，但功能上已经新增或替换了人物小传。

修正规则：

> `history/countries` 等运行时创建文件，只有在所有desc值与原版等效、没有新增有效本地化引用，并且删除后不会丢失人物小传时，才能列为冗余。

因此：

```text
v130a-4 full_redundant_candidates：7 → 0
v130a-1c 同名指标：7 → 0
```

本轮只记录修正，不修改v130a底库。
